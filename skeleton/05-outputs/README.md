Un livrable fini est à ce niveau. Les livrables se rangent par **maturité**, jamais par genre : un axe de maturité ne devient pas obsolète, un catalogue de types de documents, si.

**La finalité d'un livrable ne redéfinit jamais une note.** Ce qui est écrit ici ne remonte pas dans `04-notes/`.

*Aucun livrable.*
