# sessions — la parole de l'auteur

Un fichier par jour, `SESSION-YYYY-MM-DD.md`. L'humain a quelque chose dans la tête, il le dit, ça entre dans le contexte.

C'est le seul canal par lequel ce qui n'a jamais été écrit peut entrer. Le fichier ne fait que s'allonger : on ajoute à la fin, on ne corrige jamais ce qui est écrit.

*Aucune session.*
