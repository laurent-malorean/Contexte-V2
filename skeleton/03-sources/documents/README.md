# documents — la matière qui arrive finie

Un article, un livre, une vidéo, une transcription, un PDF, une page web. Elle existe comme objet fini, elle ne bougera plus.

Une fiche par source à ce niveau. Le fichier reçu et son texte sont rangés en dessous.

| | |
|---|---|
| [raw/](raw/README.md) | le fichier d'origine, tel qu'il est arrivé |
| [fulltext/](fulltext/README.md) | son texte, quand le format n'était pas lisible |

**Ce qui sera analysé est le texte intégral, jamais un résumé.** Une source dont l'extraction a échoué garde sa fiche — elle existe, elle est identifiée — mais ne produit aucune note tant que sa matière n'est pas figée.

*Aucun document.*
