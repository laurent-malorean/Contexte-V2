# fulltext — les textes extraits

Le texte d'une source dont le format n'était pas directement lisible : un PDF, une vidéo, un son.

Un fichier ici est vide de mise en forme et complet. Si l'extraction a échoué, le fichier porte un marqueur d'échec visible plutôt que d'être vide — un fichier vide laisse croire qu'on a lu.

*Aucun texte extrait.*
