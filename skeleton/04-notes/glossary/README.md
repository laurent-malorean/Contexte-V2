# glossary — les mots du domaine

`GLO00001-terme.md`

Une entrée stabilise un terme pour le rendre utilisable dans les décisions, les liens et les livrables.

Un mot va au glossaire, une proposition va en note atomique : la première note pense, la seconde définit.

*Aucune entrée.*
