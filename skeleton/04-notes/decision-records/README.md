# decision-records — les arbitrages sur le sujet

`DRE00001-la-decision-en-une-phrase.md`

Un record conserve une décision structurante prise **sur le sujet du contexte** : le contexte qui l'a rendue nécessaire, les options écartées, ce qui a été tranché, les conséquences acceptées. Il répond au pourquoi, jamais au comment.

Une fois acté, il ne se réécrit jamais. Il peut être remplacé, déprécié, rejeté — jamais modifié sur le fond, jamais supprimé.

Sa valeur se mesure au nombre de discussions qu'il supprime, pas au nombre d'entrées : quelques-uns suffisent, un registre pléthorique n'est plus lu.

À ne pas confondre avec [01-state/decisions.md](../../01-state/decisions.md), qui porte sur le contexte comme outil.

*Aucun record.*
