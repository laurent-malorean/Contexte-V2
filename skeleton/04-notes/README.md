# 04-notes — la connaissance

Ce qu'on a compris à partir des sources. Une note est neutre : elle ne se met jamais en forme pour un livrable.

| | | |
|---|---|---|
| [atomic/](atomic/README.md) | `ATO` | une idée par note |
| [thematic/](thematic/README.md) | `THM` | un angle qui relie plusieurs notes |
| [glossary/](glossary/README.md) | `GLO` | un terme du domaine |
| [decision-records/](decision-records/README.md) | `DRE` | un arbitrage tranché sur le sujet |

Trois règles valent pour les quatre types :

- **toute note a une source identifiable**, y compris quand cette source est la parole de l'auteur ;
- **une note n'est jamais supprimée** : elle est remplacée, reste en place marquée comme telle, et pointe vers celle qui prend le relais — qui pointe en retour vers elle ;
- **tout lien est expliqué, bidirectionnel, et sa relation est nommée.**
